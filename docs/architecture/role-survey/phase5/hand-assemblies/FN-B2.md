# Agent terrain audit interne

**Type d’organisation:** international NGO  
**Langues:** Français  

## Le poste
Comme agent terrain d’audit interne à Goma, République démocratique du Congo (RDC), vous évaluez les processus de transfert monétaire et les risques pour les communautés, avec déplacements ruraux réguliers.

## Ce que vous ferez
- Vous évaluez les processus de terrain à Goma et en zones rurales, puis recommandez des corrections datées à l’équipe pays.
- Vous vérifiez chaque semaine la qualité des enquêtes et données de transfert monétaire par rapport aux normes de l’unité.
- Vous contrôlez le respect des politiques de terrain et classez chaque écart avec preuves dans le dossier d’audit.
- Vous signalez les risques de fraude, de corruption et pour les communautés uniquement via le canal officiel.
- Vous enregistrez chaque plainte dans le suivi le jour même, avec courtoisie et les pièces jointes requises.
- Vous recueillez le regard des parties prenantes locales sur la qualité du programme dans leur communauté.
- Vous voyagez selon le plan de sécurité, y compris en zones rurales, pour les missions prévues au plan d’audit.
- Vous utilisez les outils numériques de collecte, ainsi que Microsoft Word et Excel, pour archiver chaque mission.
- Vous vérifiez la cohérence des dossiers bénéficiaires sur le terrain afin de prévenir toute erreur de versement.
- Vous préparez un compte rendu écrit après chaque mission rurale avec constats vérifiés et responsables désignés.

## Résultats attendus
- Chaque mission de terrain produit des constats, preuves et recommandations datées pour l’équipe pays.
- Les plaintes et les risques communauté sont dans le canal officiel avant la fin du jour ouvrable.

## Profil recherché
- Le profil recherché exige : diplôme universitaire dans un domaine pertinent.
- Expérience de collecte de données ou de travail de terrain.
- Le profil recherché exige : expérience d’audit de terrain et d’analyse de données.
- Le profil recherché exige : capacité à voyager régulièrement, y compris en zones rurales.
- Le profil recherché exige : maîtrise des outils numériques de collecte de données.

## Souhaitable
- Maîtrise du lingala et des autres langues couramment parlées à Kinshasa est un atout.

## Conditions de terrain
- Les déplacements ruraux suivent le plan de sécurité; le rythme de voyage est régulier selon le plan d’audit.
