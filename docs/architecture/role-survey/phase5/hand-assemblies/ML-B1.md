# Monitoring evaluation and learning specialist

**Organisation type:** domestic charity / foundation  


## The role
You provide monitoring, evaluation and learning support for the youth aquaculture programme from Kisumu with county travel.

## What you will do
- You provide monitoring, evaluation and learning support for the youth aquaculture programme across named counties.
- You travel between Kisumu, Kakamega, Homa Bay, Busia, Siaya, Kilifi and Nairobi to check field data against definitions.
- You maintain indicator definitions and reporting rules so county teams enter results the same way.
- You facilitate a learning session after each major milestone and capture owners for follow-up actions.
- You apply agreed confidentiality rules to programme datasets, including access lists and secure storage checks.
- You report monitoring findings for adaptive management to programme leads within ten working days of each review.
- You keep the results framework current when indicators change and brief field teams before the next data cycle.
- You quality-check a sample of field records each month and document corrections before donor reporting.
- You file county visit notes within three working days so the Kisumu desk can see which sites need follow-up.

## Clear outcomes
- County teams submit comparable indicator data against one shared results framework.
- Learning actions from each milestone session have named owners and a follow-up date.

## Must-haves
- Candidates must show experience delivering MEL for livelihoods or agriculture programmes.
- Candidates must show able to travel to named counties and Nairobi.
